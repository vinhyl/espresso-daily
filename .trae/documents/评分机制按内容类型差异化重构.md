# 评分机制按内容类型差异化重构

> **⚠️ 历史文档**（2026-08-06）：本方案记录的是上一轮 6 类型 × 6 维度设计，**已被 [评分机制优化方案_从实际出发.md](评分机制优化方案_从实际出发.md) 替代**。当前代码实现以新方案为准（3-4 维/类型 + relevance 否决 + 初筛硬门）。本文件保留作历史参考，不作为当前实现依据。

## 背景与问题诊断

### 现状（[src/score.py](file:///Users/vvvvvv/Documents/ai projects/espresso-daily/src/score.py) 2026-08-06 重构后）

六维评分 `relevance / novelty / actionability / evidence / params / timeliness` 对所有 `content_type` 共用，仅满分权重按类型差异化（`CONTENT_TYPE_DIM_PROFILES`）。总分恒为 100，`min_score=60` 门槛不变。

### 实际数据暴露的问题（44 条已发布内容）

| 现象 | 证据 | 根因 |
|---|---|---|
| 分数集中、无区分度 | 72 分 15 条、62 分 10 条（双峰） | LLM 中庸倾向 + 维度不适配导致每维都打"中性分" |
| 低质内容漏网 | [2026-08-06-01.md](file:///Users/vvvvvv/Documents/ai projects/espresso-daily/content/2026-08-06-01.md) 咖啡健康研究（违反项目定位）以 60 分进站 | 初筛 `健康` 关键词未生效，min_score 兜底失效——维度间凑分就能过 |
| 维度与类型错配 | 对 `news` 评 `params`（行业消息无参数可言）、对 `announcement` 评 `actionability`（公告无操作步骤）、对 `community_case` 评 `evidence`（社区个案天生低证据） | 即使权重压到 5 也只是"勉强凑数"，LLM 仍会在不适配的维度上打 0 拉低总分 |
| `timeliness` 定义与名字脱节 | 字段名仍是 `timeliness`（时效性），但 rubric 重定义为"内容有效时间"——对 `news`/`announcement` 这种"今日事件"反而低分，与日报"今日资讯流"定位相反 | 价值方向反了 |

### 用户决策

- **维度差异化程度**：每 `content_type` 独立维度集（彻底解决"维度不适配"根因）
- **前端展示**：仅内部用，前端不变（不动模板/CSS/JS，仅改 `src/score.py` 与 `src/quality_report.py`）

---

## 设计原则

1. **每个 `content_type` 有自己的维度集**，维度键、维度数、满分配置都按类型设计；总分仍归一为 100，`min_score=60` 语义不变
2. **公共维度仅 `relevance`（意式相关性）**——所有类型都保留，但权重不同
3. **类型专属维度**反映该类型内容的真实价值点，能独立判断且拉开区分度
4. **每维满分是 5 的倍数**，便于 LLM 心算
5. **`timeliness` 仅在 `news`/`announcement` 类型出现**，重定义为真正的"时效性"（当天/本周/本月）
6. **旧内容兼容**：`parse_dims` 不强校验 key，旧 frontmatter 的 `score_dims` 仍可被读取（前端不展示分项，用户无感知）；不重评旧内容

**改写 `_norm_dims(raw, content_type)`**：按 `dim_keys(content_type)` 遍历裁剪，缺失维度取该维满分一半。

**改写 `_rule_dims(item, hint, content_type)`**：按类型的维度键分别给启发式分；为每个新维度准备关键词词表（见改动 2），或对没有现成关键词的维度给中性基线（该维满分的 50-60%）。

## 假设与决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 维度集数量 | 6 套（每个 content_type 一套） | 用户已确认"每类型独立维度集" |
| 公共维度 | 仅 `relevance` | 所有类型都需要意式相关性这个基础门槛 |
| `evergreen` 维度 | 仅出现在 `expert_experiment`/`research`/`independent_review`/`community_case` | 原理性内容与长期参考价值强相关；`news`/`announcement` 用 `timeliness` 替代 |
| `timeliness` 维度 | 仅出现在 `news`/`announcement` | 重新定义为真正的"时效性"（当天/本周/本月），与日报"今日资讯"定位一致 |
| 旧内容处理 | 不重评，兼容读取 | 用户未要求重评；前端不展示分项，用户无感知 |
| 前端展示 | 不改 | 用户已确认"仅内部用" |
| 质量报告 | 仅追加按 `content_type` 平均分（可选） | 不做维度级聚合（旧内容键集不同，混在一起无意义） |
| `min_score` 阈值 | 保持 60 | 总分仍归一为 100，门槛语义不变 |
